# 📧 Smart Email Assistant

A Smart Email Assistant built using **Spring Boot**, **React**, and **AI APIs** to help users generate professional email replies, improve email writing, and increase productivity. The application uses AI to create context-aware responses with different writing tones such as Professional, Friendly, and Formal.

---

## 🚀 Features

- ✉️ AI-powered email reply generation
- 📝 Generate replies based on email content
- 😊 Choose different reply tones (Professional, Friendly, Formal)
- ⚡ Fast and accurate response generation
- 🔐 Secure backend using Spring Boot
- 🌐 REST API integration
- 💻 Responsive and user-friendly interface
- 📋 Copy generated email with one click

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/ishant-prog/Smart-Email-Assistant.git
```

### Backend

```bash
cd backend
mvn clean install
mvn spring-boot:run
```

### Frontend

```bash
cd frontend
npm install
npm start
```

---

## 💡 How It Works

1. User enters an email or message.
2. Selects the desired reply tone.
3. The frontend sends the request to the Spring Boot backend.
4. The backend communicates with the AI API.
5. AI generates a context-aware email reply.
6. The generated response is displayed to the user.
